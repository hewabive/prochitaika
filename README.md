# Прочитайка

Браузерное приложение для Android, которое учит ребёнка читать по слогам.

**Открыть:** https://hewabive.github.io/prochitaika/ (в Google Chrome на телефоне, затем
меню ⋮ → «Добавить на главный экран»).

На экране появляется слово. Ребёнок нажимает 🎤 и читает его вслух. Если слово
прочитано правильно, сыплется конфетти, показывается картинка и звучит похвала.
Картинку специально не показываем заранее, иначе ребёнок угадает слово по ней.

## Уровни

| Уровень | Как показано слово | Слова |
|---|---|---|
| 1. Первые слоги | каждый слог на отдельной плашке, нажатие озвучивает слог | ма-ма, ли-са |
| 2. Слоги-дужки | слово целиком, слоги разного цвета с дужками, тоже озвучиваются | кот, ма-ши-на, ли-мон |
| 3. Целое слово | просто слово, дужки по кнопке «Подсказка» | кошка, звезда |
| 4. Длинные слова | просто слово, дужки по кнопке «Подсказка» | черепаха, мороженое |

После неудачной попытки появляются кнопки для взрослого: «Засчитать» (если распознавание
ошиблось) и «Пропустить». После двух неудач появляется «Послушать», а на уровнях 3–4
сами собой включаются дужки.

## Запуск на компьютере

```bash
npm start        # http://localhost:8080, открыть в Google Chrome
npm test         # проверка словаря и логики сравнения слов
```

Никаких зависимостей ставить не нужно, достаточно Node.js 20 или новее.

## Публикация

Сайт живёт на GitHub Pages. При каждом `git push` в ветку `main` GitHub Actions
(`.github/workflows/pages.yml`) запускает `npm test` и, если тесты прошли, публикует папку
`public/`. Через пару минут изменения появятся на сайте. Ход публикации виден на вкладке
**Actions** репозитория. Если тесты упали, на сайте остаётся предыдущая рабочая версия.

Микрофон в браузере работает только по **HTTPS** (или на `localhost`). GitHub Pages даёт HTTPS
автоматически. Чтобы проверить изменения на телефоне до публикации, в домашней сети можно
запустить `HOST=0.0.0.0 npm start`, а на телефоне в Chrome открыть
`chrome://flags/#unsafely-treat-insecure-origin-as-secure`, вписать `http://<IP-компьютера>:8080`,
включить флаг и перезапустить Chrome.

## Распознавание речи

Используется Web Speech API, встроенный в Chrome. На Android звук отправляется в сервис
распознавания Google: бесплатно и без ключей, но нужен интернет.
Код распознавания лежит в `public/js/speech.js`. Если Google будет плохо понимать
детскую речь, этот модуль можно заменить на другой движок, не трогая остальное.

Слово засчитывается, если его удалось собрать из услышанного, даже кусками:
«ма ши на» и «маши на» засчитаются за «машина». В словах от 6 букв прощается одна
ошибка распознавания, в коротких нужно точное совпадение, иначе «рука» прошла бы за «река»
(`public/js/match.js`).

## Как добавить или поменять слова

Все слова лежат в `public/js/words.js`:

```js
['ко-ро-ва', '🐄'],
```

Слоги разделяются дефисом, картинка — любой эмодзи. Деление на слоги задано вручную,
поэтому его можно подогнать под вашу методику (например, «ко-шка» вместо «кош-ка»).
После правки запустите `npm test`: тест проверит, что в каждом слоге ровно одна гласная
и слова не повторяются.

## Файлы

```
public/
  index.html            разметка всех экранов
  css/style.css         оформление
  js/app.js             логика игры
  js/words.js           словарь по уровням
  js/match.js           сравнение услышанного со словом
  js/speech.js          распознавание речи
  js/tts.js             озвучка слогов
  js/effects.js         конфетти и победная мелодия
  sw.js, manifest.webmanifest, icons/   установка на телефон, работа без сети
server.js               простой сервер для разработки
test/                   тесты
```
